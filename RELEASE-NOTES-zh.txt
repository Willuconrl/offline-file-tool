二、本版内容
------------
· 五个模块：批量重命名、图片压缩/转换（含 HEIC 输入）、PDF 合并/拆分、图片水印、音频格式转换
· 音频转换支持 11 种目标格式：MP3 / WAV / FLAC / AAC(M4A) / OGG / ALAC / Opus / WMA / AMR-NB / AC3 / WavPack
  （APE 仅可解码，界面中已停用）
· 浅色 / 深色主题，首次运行跟随系统，切换后记住选择
· 5 种界面语言：简体中文 / 繁體中文 / English / 日本語 / 한국어
· 完全离线：无网络请求代码、无统计、不上传任何文件

三、GitHub 上传方式（维护者参考）
---------------------------------
· 仓库内容（源码 / ui / scripts / packaging / 文档）：直接上传，见同目录 _upload 快照。
· 二进制（两个 exe 与完整版 ZIP）：作为 **Release 资产** 上传。
  原因：GitHub 仓库单文件上限 100 MB（网页拖拽上传约 25 MB），而完整版 ZIP 为 169 MB；
  Release 资产单文件上限 2 GB，适合放二进制。
· 仓库 .gitignore 已排除 /dist 与 /ffmpeg，请勿把 400+ MB 的二进制提交进 Git 历史。

四、许可证合规（随附 FFmpeg 时必读）
------------------------------------
· 随附的 FFmpeg 启用了 --enable-gpl --enable-version3，即 **GPL v3** 构建。
· 它以独立可执行程序的形式随包分发，由主程序以命令行方式调用，**未链接进主程序**，
  属于"聚合分发"（separate programs on the same medium）。
  因此：FFmpeg 适用 GPL v3（附 LICENSES/GPL-3.0.txt 即可），主程序仍为 MIT。
· 切勿将 FFmpeg 静态链接进主程序 —— 那样整个软件必须按 GPL 发布，MIT 授权将被覆盖。
· 用户在包内可自行替换 ffmpeg/bin 下的可执行文件，满足 GPL 的可替换性要求。

五、复现打包
------------
    pwsh -File scripts\finalize.ps1          # 测试 + 检查 + 构建 + 生成 dist 内 exe
    pwsh -File scripts\package-release.ps1   # 生成完整版 ZIP（版本号自动取自 tauri.conf.json）

package-release.ps1 会复制主程序与组件、写入带 BOM 的 UTF-8 说明、校验 GPLv3 正文、
生成 SHA256SUMS.txt、打 ZIP，并解压后实跑 ffmpeg -version / ffprobe -version 自检。
